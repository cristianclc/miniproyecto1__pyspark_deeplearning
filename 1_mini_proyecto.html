Análisis Predictivo - Click-Through Rate#

Contexto del Proyecto#

El objetivo del proyecto es el de construir un modelo de clasificación supervisada usando MLP - (MultiLayer Perceptron) con el fin de predecir si un usuario hará clic en un anuncio móvil

Base de Datos: Click-Through Rate Prediction#

Origen#

El Dataset utilizado en este proyecto corresponde a Click-Through Rate Prediction, usado inicialmente en competencias de Kaggle con el fin de evaluar algoritmos para la predicción de clicks en publicidad digital.

Características#

  • Volumen: 40,428,967 registros de usuarios.

  • Variables: 24 variables.

  • Período: 11 días de información.

  • Completitud: No contamos con valores faltantes en el Dataset.

Variables analizadas#

  • id: Identificador único de cada impresión de anuncio. Cada fila del dataset representa una ocasión en la que un anuncio fue mostrado a un usuario.

  • hour: Marca temporal del anuncio (formato: YYMMDDHH)

  • banner_pos: Posición del banner en la página web.

  • site_id: Identificador único del sitio web donde se mostró el anuncio.

  • site_domain: Dominio del sitio web donde se muestra el anuncio.

  • site_category: Categoría temática del sitio web.

  • app_id: Identificador único de la aplicación móvil donde se mostró el anuncio.

  • app_domain: Dominio asociado a la aplicación.

  • app_category: Categoría de la aplicación.

  • device_id: Identificador único del dispositivo.

  • device_ip: Dirección IP del dispositivo que vio el anuncio.

  • device_model: Modelo del dispositivo.

  • device_type: Tipo de dispositivo.

  • device_conn_type: Tipo de conexión de red del dispositivo.

  • C1: variable categórica anonimizada

  • C14–C21: variables categóricas anónimas

Variable Objetivo#

  • click: indicador de si hubo clic

Dada la alta cardinalidad de las variables categóricas restantes, optamos por utilizar Target Encoding (codificación por objetivo) en lugar de One Hot Encoding. Esta técnica consiste en reemplazar cada categoría por el valor promedio de la variable objetivo para esa categoría, lo que evita la explosión dimensional que generaría One Hot Encoding y que aumentaría significativamente el costo computacional del entrenamiento. Adicionalmente, agruparemos las categorías raras para evitar estimaciones poco robustas de Target Enconding basadas en pocas observaciones.

Conclusiones#

  • Variables identificadoras: Se eliminaron aquellas columnas que funcionaban como identificadores únicos (id, device_ip, device_id, app_id, site_id), ya que no aportaban valor predictivo y podían generar ruido en el modelo.

  • Variables temporales: La variable hour mostró un patrón claro de estacionalidad diurna, con tasas de clics más altas en horarios específicos (madrugada, mañana temprano y tarde). En cambio, dia, mes y año serán excluidas dado que el período analizado no permite extraer patrones útiles a partir de ellas.

  • Variables anónimas y categóricas: La mayoría presentan distribuciones son similares entre clicks y no clicks, lo que sugiere que la contribución de estas variables al modelo podría manifestarse principalmente a través de interacciones no linales. Además, eliminaremos la variable c14, ya que presenta una alta correlación con la variable c17. Este nivel de correlación indica que ambas variables contienen información redundante y por lo tanto, describen patrones muy similares dentro del conjunto de datos.

Modelado#

Procederemos a la etapa de modelado utilizando dos enfoques complementarios:

En Scikit-learn:

  • Aplicaremos Target Encoding para codificar las variables categóricas, reemplazando cada categoría por la tasa de clics promedio correspondiente.

  • Para evitar estimaciones extremadamente bajas o altas en aquellas categorías con pocas observaciones, agruparemos las categorías raras (aquellas con frecuencia baja) antes de la codificación.

En PySpark:

Dado que PySpark no cuenta con una implementación nativa de Target Encoding, utilizaremos un enfoque alternativo:

  • StringIndexer para convertir las variables categóricas en índices numéricos.
